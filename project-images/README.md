# CRISENTRA AI
### AI-Powered Disaster Message Analyzer

CRISENTRA AI is an AI-powered disaster intelligence application designed to analyze emergency messages and support disaster response through automated classification, information extraction, and priority assessment.

The system transforms disaster-related messages into structured intelligence to help identify emergencies, understand affected people, and support rescue coordination.

## Features

- **Disaster Message Classification** – Classifies disaster messages using a trained RoBERTa model.
- **Emergency Information Extraction** – Extracts deaths, injuries, trapped people, and emergency-related information.
- **Actionability Assessment** – Evaluates whether a message requires emergency response.
- **Completeness Assessment** – Identifies missing information in crisis reports.
- **Priority Assessment** – Assigns priority levels to incoming crisis messages.
- **Crisis Reporting** – Allows users to submit disaster reports with text, images, and voice.
- **Rescue Dashboard** – Supports rescue teams in reviewing incoming emergency reports.
- **Disaster Map** – Displays crisis locations for geographical awareness.
- **Analytics Dashboard** – Provides overall disaster intelligence statistics.
- **Feedback System** – Supports feedback and rescue response communication.
- **AI Assistant** – Provides assistance related to disaster information.

## Project Workflow

1. User submits a disaster-related message.
2. The system analyzes the message using NLP and machine learning.
3. Disaster information is extracted from the message.
4. Actionability, completeness, and priority are assessed.
5. Crisis reports are presented to the rescue interface.
6. Rescue teams review reports and provide responses.
7. Analytics support disaster intelligence monitoring.

## Project Objective

To explore how Data Science, Natural Language Processing, and Artificial Intelligence can be applied to real-world disaster management by converting emergency messages into actionable intelligence.
