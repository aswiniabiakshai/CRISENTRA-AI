# CRISENTRA AI
### AI-Powered Disaster Message Analyzer

CRISENTRA AI is an AI-based disaster intelligence application designed to analyze emergency messages and support disaster response through automated classification, information extraction, and priority assessment.

## Features
- Disaster message classification using RoBERTa
- Emergency information extraction
- Actionability and completeness assessment
- Priority scoring
- Crisis reporting and analysis
- Interactive disaster map
- User and rescue team interfaces
- AI Assistant

## Technologies Used
- Python
- NLP and Machine Learning
- PyTorch
- RoBERTa
- HumAID Dataset
- React
- TypeScript
- Tailwind CSS
- Node.js
- Vite

## Project Purpose
To explore how Data Science and Artificial Intelligence can support disaster response by transforming emergency messages into actionable intelligence.
